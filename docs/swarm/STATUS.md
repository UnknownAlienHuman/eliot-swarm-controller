# Что проверено и что гипотеза

> Источник фактов: целевая архитектура v2.6 (27.11.2026), раздел 1 «Статус механизмов» и раздел 13а; ниже сохранены исторические результаты с уточнёнными границами доказательств. Сводка — [ARCHITECTURE.md](ARCHITECTURE.md), навигация — [INDEX.md](INDEX.md).

**Зачем.** Правило 11: механизм попадает в первую волну, только если без него задача не переживает сбой или его эффект измерен. Агент, который опирается на механизм, должен знать, измерен ли он. Не выдавать гипотезу за факт.

**Метки в документах.** «измерено», «доказано в песочнице», «доказано в прототипе» — запуском; «проверено по коду», «вывод по коду» — чтением исходников, запуском нет; «только документация», «по CHANGELOG» — официальные страницы; «гипотеза» — не проверено, указан план замера или этап; «отложено», «убрано» — не в первой волне. Пороги детектора, сроки и бюджеты — стартовые значения.

**Граница проверки PR #1255.** На `main@5b125876be0f1a9ee8e94d93e8e3ba7654ffd8b4` проверены код и инструменты документации. Названные ниже каталоги `eliot-swarm-research/2026-11-27-v2.2-verify` и `2026-11-27-payments`, исходные логи и манифесты прогонов в этом checkout отсутствуют. Числа из v2.6 — сообщённые результаты прототипов; здесь они независимо не воспроизведены. Перенос результата на текущий бинарник, другой harness, Windows или настоящий GitHub требует соответствующего прогона.
