# Плагин notify (уведомления владельцу)

> Источник фактов: целевая архитектура v2.6 (27.11.2026). Текст ниже шапки перенесён из неё дословно; «раздел N» и «приложение X» — номера v2.6, ссылка ↗ ведёт туда, где он теперь. Общая суть — [ARCHITECTURE.md](../../ARCHITECTURE.md), связи — [GRAPH.md](../../GRAPH.md), навигация — [INDEX.md](../../INDEX.md).

**Зачем.** Владелец просил уведомления: блокировки, held, сбой демона, исчерпанный бюджет, облачная сессия orphan. Telegram, почта и т. п.

**Инварианты.** swarm notify работает без живого демона: при сбое демона его вызывает служба ОС (OnFailure= у systemd, действие восстановления SCM у Windows).

**Статус.** Первая волна; deploy-плагин отложен, notify остаётся.

## Падение демона (раздел 3)

- Упал демон: служба ОС перезапускает его, не больше 5 раз за 5 минут. Дальше уведомление шлёт сама служба ОС (OnFailure= у systemd, действие восстановления SCM у Windows) командой swarm notify, которая не требует живого демона; при следующем старте в списке задач появляется обычная задача «починить Swarm» с логом падения. Текст паники возвращается в crash.rs:178, иначе причина падения теряется.
